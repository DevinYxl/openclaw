# Shared Skills - Multi-Agent Collaboration Protocols

## 概述

共享技能库，为所有 Agent 提供标准化的协作协议。

## 目录结构

```
shared/
├── SKILL.md              # 本文件
├── task-delegate.md      # 任务委托协议
├── result-aggregator.md  # 结果聚合协议
├── memory-sync.md        # 记忆同步协议
└── project-template.md   # 项目模板定义
```

## 核心协议

### 1. 任务委托 (task-delegate.md)

- 标准任务分配格式
- sessionKey 命名规范
- 回调机制

### 2. 结果聚合 (result-aggregator.md)

- 结果汇报格式
- 状态码定义
- 聚合流程

### 3. 记忆同步 (memory-sync.md)

- 记忆文件更新规范
- 上下文传递格式
- 冲突处理

### 4. 项目模板 (project-template.md)

- 标准项目结构
- 必需文件清单
- 初始化流程
